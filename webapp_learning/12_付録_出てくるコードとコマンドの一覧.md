# 12 付録: 出てくるコードとコマンドの一覧（機能ごと）

## この一覧について

00〜11 の巻のコードに出てくる、**HTML のタグ・CSS の項目・TypeScript と React・Python と Django・Rust と Topcoat・SQL・コマンドなど 939 個**を、**50 の分類**に分けて、1 つずつ説明した一覧です。

- **本文との関係:** どの部品も、本文の中で**初めて出てくるコードのすぐ下**に、「**▶ ここで初めて出てくるコード**」の箱で同じ説明を載せています。この一覧は、それを機能ごとに並べ直した物です。
- **使い方:** 「この `useEffect` は何だっけ？」「`.filter()` は Django と TypeScript で何が違う？」と思ったら、下の「分類の一覧」から分類を選んで探してください。HTML 版（`webapp_learning\html`）なら、`Ctrl` ＋ `F` で、コードの名前で探すのがいちばん速いです。
- **「初めて出てくる所」の列:** その部品が最初に出てくる巻と章です（`08 前編 3. 設定を読む` は、08 の前編の 3 章）。そこで、実際にどう使われているかを見られます。
- **同じ綴りでも、言語が違えば別の物**として、それぞれの言語の分類に載せています。例えば `.filter()` は、TypeScript では配列から条件に合う物を集めるメソッド、Django ではデータベースの行を条件でしぼるメソッドです。
- **分類の並び:** 学ぶ順（道具 → HTML・CSS → TypeScript・React → Python・Django → Rust・Topcoat）に並べています。「画面に出す」から後ろの分類は、主に 07〜10 の Rust・Topcoat・SQL・メールの部品です。
- **読者が自分で書く名前**（`Request`・`list_requests` など、練習アプリのコードで自分で作る型や関数の名前）は、作った所の本文で説明しているので、この一覧には入れていません。ただし、作るより前に先に出てくる物（`Outbox`・`<FormPage>` など）は、「練習アプリで作る物」の表に、意味を載せています。

> **ヒント:** 1 つの部品を覚えたら、その分類の表の、近くにある物も読んでみてください。例えば `Django` の表には、行を作る（`.create()`）・探す（`.filter()`・`.first()`）・数える（`.count()`）・保存する（`.save()`）が並んでいます。一緒に覚えると、使える場面がぐっと増えます。
