Web アプリ開発 学習資料

プログラミングや Web の経験がほとんど無い人が、社内向けの業務 Web アプリを作れるようになるための資料です。依頼・承認の練習アプリを作りながら、HTML・CSS・TypeScript・React・Python・Django・Rust・Topcoat・メール送信（SMTP リレー）・安全とテストを学びます。図と、練習アプリの本物の画面の写しを多く入れています。

前提: onprem に建てる

作った練習アプリは、onprem/ の資料のとおりに、会社の Windows Server（HTTP の 80 番・IIS・仮想マシンの中の PostgreSQL・Microsoft 365 の SMTP リレー）に建てる前提で作ります。設定の名前（環境変数）も、onprem の WinSW の XML とそろえています（00 学習ガイドの 3.1）。
