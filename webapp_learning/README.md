# Web アプリ開発 学習資料

プログラミングや Web の経験がほとんど無い人が、社内向けの業務 Web アプリを作れるようになるための資料です。**依頼・承認の練習アプリ**を作りながら、HTML・CSS・TypeScript・React・Python・Django・Rust・Topcoat・メール送信（SMTP リレー）・安全とテストを学びます。図と、練習アプリの本物の画面の写しを多く入れています。
