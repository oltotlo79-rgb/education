## 前提: onprem に建てる

作った練習アプリは、`onprem/` の資料のとおりに、会社の Windows Server（HTTP の 80 番・IIS・仮想マシンの中の PostgreSQL・Microsoft 365 の SMTP リレー）に建てる前提で作ります。設定の名前（環境変数）も、onprem の WinSW の XML とそろえています（00 学習ガイドの 3.1）。
