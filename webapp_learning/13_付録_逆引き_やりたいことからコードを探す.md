# 13 付録: 逆引き — やりたいことからコードを探す

## この逆引きについて

12 付録「出てくるコードとコマンドの一覧」は、「この `useEffect` は何だっけ？」のように、**コードから意味を引く**ための物です。この 13 付録は、その反対です。「**一覧を条件でしぼり込みたい**」「**数を 3 けたごとに区切って表示したい**」のような、**やりたいことから、書き方を引く**ための物です。

- **全部で 443 個**の「やりたいこと」を、**17 の分類**に分けています。分類は、学ぶ順（道具 → HTML・CSS → TypeScript・React → Python・Django → Rust・Topcoat → SQL・メール・安全）です。下の「分類の一覧」から選ぶか、HTML 版（`webapp_learning\html`）で `Ctrl` ＋ `F` を押して、やりたいことの言葉（「しぼる」「並べかえる」「送る」など）で探してください。
- **同じやりたいことでも、言語ごとに書き方が違います。** 例えば「並びから条件に合う物だけを集める」は、TypeScript では `items.filter(…)`、Python では `[r for r in rows if …]`、Django では `Request.objects.filter(…)` です。それぞれの言語の分類に載せています。
- **「書き方」の列:** そのまま使える形の、短いコードです。`…` の所は、自分の場面に合わせて書きます。
- **「ひとこと」の列:** 気をつけることや、結果の例です。くわしい意味は、12 付録の一覧と、本文の「▶ ここで初めて出てくるコード」の箱にあります。
- **「出てくる所」の列:** その書き方が、00〜11 で初めて出てくる巻と章です（399 個）。
- **「＋ 合わせて覚える」:** 本文で使った書き方と一緒に覚えておくと、すぐ役に立つ書き方です（44 個）。この付録で足しました。使う前に、12 付録の一覧や、それぞれの説明書で、くわしい使い方を確かめてください。

> **ヒント:** 練習アプリを作っている時に「こういう時はどう書くんだっけ？」と思ったら、まずこの付録を開いてください。1 つの分類の表を上から下まで一度ながめておくと、あとで探す時に思い出しやすくなります。
