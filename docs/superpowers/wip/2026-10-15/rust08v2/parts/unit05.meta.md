title: Topcoat のセッションの一生
---checklist
- ☐ セッションの一生（start → 毎回の照合 → stop）を、クッキーと sessions 表の両方で追いかけられる
- ☐ Topcoat の受け持ち（トークンを作って運び、ハッシュを渡す）と、RustNote の受け持ち（記録・照合・期限・取り消し・掃除）を分けて言える
- ☐ ログアウトで DB の記録を消さないと、写し取られたクッキーが使い続けられることを説明できる
- ☐ 照合で期限を見る理由と、期限切れの行がログインのときの `delete_expired` で消えることを言える
- ☐ サーバーの側で行を消して、全部の端末のセッションを終わらせられることを確かめられる
- ☐ 期限を延ばすときの `session::refresh` と、DB の `expires_at` の更新を組にする作り方を説明できる
---glossary
| セッション | ログインからログアウトまでの、「この人は alice だ」とサーバーが覚えている状態 |
| サーバーの側のセッション | 記録を DB に持つ作り方。サーバーで消せば、すぐに使えなくできる |
| `session::start` | 新しいトークンを作ってクッキーに入れ、`token_hash` と `expires_at` を返す Topcoat の関数 |
| `session::stop` | クッキーを消すように伝え、そのトークンの `token_hash` を返す関数 |
| `session::refresh` | 同じトークンのまま、期限を延ばす関数。RustNote は使っていない |
| `expires_at` | セッションの有効期限。1970 年からの秒数で `sessions` 表に入れる |
| `delete_expired` | 期限切れのセッションの行を消す関数。RustNote はログインのときに呼ぶ |
| E0609 | その型に、その名前の項目（フィールド）が無いエラー |
