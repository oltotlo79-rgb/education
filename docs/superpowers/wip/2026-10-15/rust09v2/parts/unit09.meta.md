title: デザインの決まり・アセット・アクセシビリティ
---checklist
- ☐ RustNote の色の変数とボタンの3種類（主・副・危険）を読み取り、新しい画面でも同じ意味で使える
- ☐ 文字と背景のコントラスト比を計算し、WCAG の AA（4.5 以上）を満たすかを数で確かめられる
- ☐ `lang`・`<h1>` が1つ・入力欄のラベル・ボタンの文字を、本物の HTML から確かめるテストを書ける
- ☐ `placeholder` がラベルの代わりにならない理由と、`<label for>` と `aria-label` の使い分けを言える
- ☐ `for` と `id` のずれや、薄すぎる色のような、見た目では気づけない間違いを、テストと計算で見つけられる
- ☐ RustNote に残る改善点（検索の入力欄のラベル・ページごとの `<title>`）を説明できる
---glossary
| アクセシビリティ | 人によって目・耳・手の使い方が違っても、誰でも使えるようにすること |
| WCAG | Web のアクセシビリティの国際的な決まり。A・AA・AAA の段階がある |
| コントラスト比 | 文字と背景の明るさの比。1〜21。AA はふつうの文字で 4.5 以上 |
| 相対輝度 | 色の明るさを 0（黒）〜1（白）で表した値。コントラスト比の計算に使う |
| `<label for="id">` | 入力欄の名前。`for` と入力欄の `id` が同じだと、つながる |
| `aria-label` | 見える文字を置かずに、読み上げソフトに名前を伝える属性 |
| `placeholder` | 入力欄の中の、薄い見本の文字。入力すると消えるので、ラベルの代わりにならない |
| `role="status"` | 読み上げソフトに「お知らせの文です」と伝える属性 |
| フォーカスの枠 | Tab キーで選んでいる所を示す枠（`outline`）。消さない |
| `viewport` | スマートフォンで、画面の幅に合わせて表示するための `<meta>` の設定 |
