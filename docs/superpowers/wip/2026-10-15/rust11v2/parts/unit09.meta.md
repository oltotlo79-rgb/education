title: 負荷試験・背圧・容量
---checklist
- ☐ oha で release の RustNote に負荷をかけ、1秒あたりの回数・パーセンタイル・状態コードの内訳を読める
- ☐ ログインの同時の数を変えて測り、CPU の数を超えると回数が減り、メモリだけが増えることを示せる
- ☐ Semaphore の整理券で、Argon2 を同時に計算する数とメモリの上限を決める背圧を入れられる
- ☐ 全部 403 でも Success rate 100% と出ること、サーバーが無くても oha は exit=0 で終わることを知っている
- ☐ 待たせる背圧と断る背圧の違いと、容量がメモリと待ち時間の先に限界が来るほうで決まることを言える
---glossary
| 負荷試験 | たくさんのリクエストを送り、速さと限界を測ること |
| oha | Rust で作られた、HTTP の負荷をかける道具 |
| Requests/sec | 1秒あたりに返せたリクエストの数 |
| パーセンタイル | 応答時間を短い順に並べたとき、何 % の所の値か（95%・99% など） |
| 背圧 | 受け付けられる量を超えた分を、待たせたり断ったりすること |
| `Semaphore` | 決まった数の整理券。`acquire().await` で1枚もらい、drop で返す |
| 容量 | 1台のマシンで受け付けられる量。CPU・メモリ・DB の、先に足りなくなるもので決まる |
