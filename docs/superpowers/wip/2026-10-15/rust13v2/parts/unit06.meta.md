title: ログイン・お知らせ・共有の状態
---checklist
- ☐ Argon2id のハッシュを spawn_blocking で作る理由と、借り物を渡すと E0521 になる理由を説明できる
- ☐ 登録されていないメールでもダミーのハッシュで照合する理由を、時間の比較（36〜41 ミリ秒と 4 ミリ秒）で説明できる
- ☐ ログイン・ログインし直し・ログアウトで、__Host-session クッキーと sessions の表がどう変わるかを、curl の結果で言える
- ☐ フラッシュメッセージが一度だけ出るしくみと、書き換えられたクッキーで何も出ない理由を言える
- ☐ AppState が Arc と Send + Sync で共有される理由を、Rc のエラー（E0277）で説明できる
---glossary
| Argon2id | パスワードをハッシュにする方式。わざと時間とメモリを使い、総当たりを遅くする |
| 塩（salt） | ハッシュにする前に足すランダムな値。同じパスワードでも、毎回違うハッシュになる |
| PHC 文字列 | `$argon2id$v=19$m=…,t=…,p=…$塩$ハッシュ` の形で、方式・設定・塩・ハッシュをまとめた文字列 |
| `spawn_blocking` | 重い計算を、非同期の処理を止めないよう、別のスレッドに任せる tokio の関数 |
| `LazyLock` | static の値を、最初に使うときに1回だけ作る型 |
| `#[memoize(as_ref)]` | Topcoat の印。1つのリクエストの中で、関数の結果を覚えておき、2回目からは参照を返す |
| `__Host-session` | Topcoat のセッションのクッキー。`__Host-` で始まる名前は、Secure と Path=/ が必須で、ドメインを指定できない |
| フラッシュメッセージ | 次の画面で一度だけ出すお知らせ。RustNote はクッキー flash に決まったコードだけを入れる |
| ユーザーの列挙 | 応答の違い（文・状態・時間）から、どのメールが登録済みかを調べること |
