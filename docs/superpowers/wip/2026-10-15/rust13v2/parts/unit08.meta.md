title: ノートの CRUD
---checklist
- ☐ 一覧・作成・詳細・編集・切り替え・削除の URL・メソッド・状態コード（200・303・400・404・409）を、curl の結果で言える
- ☐ module_param! で {id} を NoteId に変え、数字でない・0・無い・他人のノートを、どれも 404 にするしくみを説明できる
- ☐ 2つのタブの編集で 409 になり、もう一度保存すると上書きされる流れと、知らせる内容の足りない所を言える
- ☐ href! に ID を渡し忘れても、コンパイルが通り、ノートがあるときだけ表示でパニックすることを説明できる
- ☐ 最後より大きいページの文と、UTC のままの日時の表示という改善点を、実際の画面で示せる
---glossary
| CRUD | Create・Read・Update・Delete。データを扱う画面の、基本の4つの操作 |
| `module_param!` | そのモジュールの URL の区切りを `{id}` のような変数にし、文字列を決まった型に変える Topcoat のマクロ |
| `path_param::<Id>` | URL の変数を読む関数。`module_param!` が作った型（`Id`）で読む |
| `#[query_params]` | URL の `?q=…&page=…` を読む型にする印。読めなければ 400 などにできる |
| `#[key(…)]` | `view!` の `for` の1つ1つに付ける目印 |
| `<details>` | 開いたり閉じたりできる HTML の部品。RustNote は作成のフォームを入れる |
| UTC | 世界の基準の時刻。日本時間は UTC より 9 時間進んでいる |
