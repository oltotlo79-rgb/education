RustNote ミニ版です。help で使い方を表示します。
> help
list          一覧を表示
add タイトル  ノートを追加（1〜80文字）
done 番号     完了／未完了を切り替え
del 番号      ノートを削除
find 語       タイトルで検索
quit          終了
> add 牛乳を買う
#1 を追加しました
> add   Rust の勉強  
#2 を追加しました
> add
入力エラー: タイトルを入力してください
> list
[ ] #1 牛乳を買う
[ ] #2 Rust の勉強
> done 1
#1 を完了にしました
> done 9
#9 は見つかりません
> find Rust
[ ] #2 Rust の勉強
> del 2
「Rust の勉強」を削除しました
> list
[x] #1 牛乳を買う
> hello
解釈できません（help で使い方を表示）
> quit
