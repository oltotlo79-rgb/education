# 設計書: 未使用技術スタック解説の追加（next/ と react_native/）

作成日: 2026-06-15

## 1. 目的・背景

`next/` と `react_native/` の教育教材は、サンプルアプリ（書籍管理 / Supabase）で
**実際に使う機能だけ** を解説している。そのため、初心者が実務へ進む際に必要な
「アプリでは使わなかったが頻出する主要機能」がカバーされていない。

本作業では、各技術スタックの章に **「発展: アプリでは使っていないが重要な〇〇」**
セクションを追記し、主要・頻出の機能を初心者向けに解説する。

対象は `next/` と `react_native/` のみ（`docs/` は対象外）。

## 2. 方針

### 2.1 配置方針
- 各章の論理的な位置に新セクションを追記する。
  - フック: 関連する既存セクションの後（例: useEffect の後に useRef 等）
  - その他: 章末（既存の「まとめ」「よくあるエラー」の前）に「発展」セクション
- 既存の章構成・本編の流れは壊さない（辞書的に引ける構成を維持）。
- 新セクションは見出しで「発展 / アプリ未使用」と明示し、本編と区別する。

### 2.2 フォーマット規約（厳守）
既存教材の規約に揃える。各サンプルコードは必ず以下の構造にする。

```
#### [コード例の名前]

> **▼ このコードがやること（先に日本語で）:** [コード全体が何をするかを専門用語を避けて2〜3文で]

​```tsx / typescript / sql など
// 日本語コメント付きコード
​```

#### ▼ コードを1つずつ分解して解説

##### 解説1: [塊1のタイトル]
​```...​```
- 専門用語を避けた説明（箇条書き）
> **用語:** [新出用語があれば1行で平易に定義]

##### 解説2: ...
（以下、意味のある塊ごとに分解）
```

- 見出しレベル: `##`=章節 / `###`=サブ節 / `####`=コード例 / `#####`=解説N。
- `react_native/03-react-basics.md` は現状この形式を採用していない（コード後に段落説明）。
  追加分は **上記の `▼` + `解説N` 形式に揃えて** 新規に書く。
- 説明は初心者向け。専門用語は極力避け、使う場合は `> **用語:**` で平易に補足。

### 2.3 サンプル方針
- すべて **独立した最小サンプル**（アプリのコードに依存しない短い例）。
- `react_native/` 系は DOM 非依存（`div`/`onClick` 等を使わず `View`/`Pressable`/`Text` 等）。
- 各機能の「本質が伝わる最小例」に絞る。網羅は「主要・頻出」まで（特殊・ニッチ機能は除外）。

## 3. ファイル別 追加内容

### 3.1 `next/02-typescript-basics.md` / `react_native/02-typescript-basics.md`
章末に「発展: アプリでは使っていない重要なTypeScript機能」を追加。

追加トピック（両ファイル共通。RN版は既存にない分も補う）:
1. ユニオン型・リテラル型 ※next版は既存にあるためRN版のみ新規、next版は確認のみ
2. Utility Types（`Partial` / `Pick` / `Omit` / `Required` / `Record`）
3. `enum`（列挙型）
4. 型ガード（`typeof` / `in` / 型述語 `x is T`）
5. `as const`
6. オプショナルチェイニング `?.` と Null合体 `??`
7. ジェネリック関数（`function wrap<T>(x: T): T[]`）

除外: `keyof`/`typeof`型演算子の深掘り、インデックスシグネチャ、`never`の高度な使い方（ニッチ）。

### 3.2 `next/03-react-basics.md`
既存: useState / useEffect / useCallback（カスタムフック内）/ カスタムフック。
追加（useEffect の後あたりに挿入）:
1. `useRef`（値の保持・DOM参照）
2. `useMemo`（計算結果のメモ化）— 単独セクションとして明示
3. `useCallback`（関数のメモ化）— 単独セクションとして明示
4. `useContext`（Props のバケツリレー回避）
5. `useReducer`（複雑な state の集約）

### 3.3 `react_native/03-react-basics.md`
既存: useState / useEffect（さわり）のみ、かつ `▼`+`解説N` 形式が未採用。
追加（フック章 §5 を拡充）— **すべて新形式・DOM非依存の例で**:
1. `useRef`（`TextInput` のフォーカス制御・タイマーID保持）
2. `useMemo`（リスト計算のメモ化）
3. `useCallback`（`FlatList` の `renderItem` 安定化）
4. `useContext`（テーマ/言語などアプリ全体の共有値）
5. `useReducer`（フォーム state の集約）
6. カスタムフック（例: `useToggle`）

### 3.4 `next/04-nextjs-basics.md`

## 4. 品質基準（完了条件）
- 各追加サンプルが「▼ やること説明 → コード → 解説N分解」の3点を満たす。
- 専門用語は平易な言い換え or `> **用語:**` で補足されている。
- RN系の例にWeb専用API（`div`/`onClick`/`localStorage`等）が混入していない。
- 各章の既存目次（あれば）に新セクションへのリンクを追加。
- Markdownのコードフェンス言語指定・見出しレベルが既存と一致。
- PDFビルド（`_build_pdfs.py` 等）を壊さない（Markdown構文として妥当）。

## 5. 対象外
- `docs/`（Django+React Web）配下すべて。
- 特殊・ニッチな機能（各章の「除外」参照）。
- 既存本文の書き換え（追記のみ。明らかな誤りを見つけた場合のみ最小修正）。
