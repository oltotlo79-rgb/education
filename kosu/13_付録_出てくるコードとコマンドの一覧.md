## この一覧について

00〜12 と 15 の巻のコードに出てくる、**PowerShell・Git・pip・npm のコマンド、HTML のタグと属性、CSS の項目、TypeScript と React、Python と Django・Django REST framework、pandas・openpyxl（Excel）、テストの道具、書式・記号・設定ファイルなど 716 個**を、**24 の分類**に分けて、1 つずつ説明した一覧です。

- **本文との関係:** どの部品も、本文の中で**初めて出てくるコードのすぐ下**に、「**▶ ここで初めて出てくるコード**」の箱で同じ説明を載せています。この一覧は、それを機能ごとに並べ直した物です。
- **使い方:** 「この `useEffect` は何だっけ？」「`.filter()` は Django と TypeScript で何が違う？」と思ったら、下の「分類の一覧」から分類を選んで探してください。Web 版（`kosu\html`）なら、`Ctrl` ＋ `F` で、コードの名前で探すのがいちばん速いです。
- **「初めて出てくる所」の列:** その部品が最初に出てくる巻と章です（`07 5. 実コード全解説：member_views.py 全2…` は、07 の 5 章。長い章の名前は、後ろを「…」で切っています）。そこで、実際にこのアプリでどう使われているかを見られます。
- **文字や記号の書き方も入っています:** f 文字列（`f'{member_name}氏の…'`）・`\n` のような特別な文字・正規表現・日時の書式（`%Y-%m-%d`）・記号（`?.`・`??`・`&&`・`**kwargs`）・HTML と JSX の属性（`for`・`htmlFor`）・`package.json` の設定・コマンドのオプションも、1 つずつ説明しています。
- **やりたいことから探す時は:** 次の 14 付録「逆引き」で、「一覧をしぼり込みたい」「Excel に書き出したい」のような、やりたいことからコードを探せます。本文に出てこない、合わせて覚えておくとよいコードも載せています。
- **同じ綴りでも、言語が違えば別の物**として、それぞれの言語の分類に載せています。例えば `.filter()` は、TypeScript では配列から条件に合う物を集めるメソッド、Django ではデータベースの行を条件でしぼるメソッドです。
- **分類の並び:** 引き継いだ人が触る順（道具 → Git → HTML・CSS → TypeScript・React → Python・Django → Excel・テスト）に並べています。
- **このアプリが自分で作った名前**（`KosuList`・`handleSearch`・`time_index` など、画面や関数の名前）は、本文のその場所で説明しているので、この一覧には入れていません（よく出てくる共通の部品 `TableContainer`・`Pagination`・`Loading` だけは載せています）。

> **ヒント:** 1 つの部品を覚えたら、その分類の表の、近くにある物も読んでみてください。例えば `Django` の表には、行を作る（`.create()`）・探す（`.filter()`・`.get()`）・数える（`.count()`）・並べかえる（`.order_by()`）が並んでいます。一緒に覚えると、使える場面がぐっと増えます。
