# 14 付録: 逆引き — やりたいことからコードを探す

## この逆引きについて

13 付録「出てくるコードとコマンドの一覧」は、「この `useEffect` は何だっけ？」のように、**コードから意味を引く**ための物です。この 14 付録は、その反対です。「**人員の一覧を条件でしぼり込みたい**」「**工数のデータを Excel に書き出したい**」のような、**やりたいことから、書き方を引く**ための物です。

- **全部で 465 個**の「やりたいこと」を、**23 の分類**に分けています。分類は、引き継いだ人が触る順（道具 → Git → HTML・CSS → TypeScript・React → Python・Django → Excel・テスト・運用）です。下の「分類の一覧」から選ぶか、Web 版（`kosu\html`）で `Ctrl` ＋ `F` を押して、やりたいことの言葉（「しぼる」「並べかえる」「送る」など）で探してください。
- **同じやりたいことでも、言語ごとに書き方が違います。** 例えば「並びから条件に合う物だけを集める」は、TypeScript では `items.filter(…)`、Python では `[r for r in rows if …]`、Django では `member.objects.filter(…)` です。それぞれの言語の分類に載せています。
- **「書き方」の列:** そのまま使える形の、短いコードです。`…` の所は、自分の場面に合わせて書きます。このアプリのモデル（`member`・`Business_Time_graph` など）を使った例も多く入れています。
- **「ひとこと」の列:** 気をつけることや、結果の例です。くわしい意味は、13 付録の一覧と、本文の「▶ ここで初めて出てくるコード」の箱にあります。
- **「出てくる所」の列:** その書き方が、00〜12 と 15 で初めて出てくる巻と章です（378 個）。
- **「＋ 合わせて覚える」:** 本文で使った書き方と一緒に覚えておくと、保守ですぐ役に立つ書き方です（87 個）。この付録で足しました。本番のアプリに入れる前に、13 付録の一覧や、それぞれの説明書で、くわしい使い方を確かめ、自分のパソコン（ローカル）で試してください。

> **ヒント:** 直したい所がある時は、「何をしたいか」を短い言葉にしてから、この付録を開いてください。1 つの分類の表を上から下まで一度ながめておくと、あとで探す時に思い出しやすくなります。
