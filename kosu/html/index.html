業務工数システム 引き継ぎ教育資料

このフォルダ（kosu/）には、本Webアプリ「業務工数システム」を 作成・運用・保守 していくために必要な知識を、プログラミング完全初心者 でも学べるようにまとめた教育資料が入っています。

🔰 このシステムを引き継いだ方は、最初に「000_引き継ぎ書_最初に読む」を読んでください。 受け取る物のチェックリスト、最初の 1 か月にやること、変更が本番に出る仕組み（master に push すると、そのまま本番へ出ます）、画面とプログラムの対応表、押す前にバックアップが要る操作、前任者に確かめることを、1 冊にまとめてあります。

アプリ本体と、この資料の置き場所: アプリのプログラム（ソースコード）は、別の場所の kosu_react フォルダの中の hozen-kosu-React/ にあります（以下、資料の中で「プロジェクト直下」と書いたら、この hozen-kosu-React/ のことです）。この資料は、それを説明する読み物で、アプリの動きには関係しません。資料を書き換えても、アプリは変わりません。

0. この資料の対象読者

  • これまでプログラミングをほとんど（あるいは全く）やったことがない方
  • このアプリの保守・運用を引き継ぐことになった方
  • 「何から手をつければいいか分からない」という状態の方

専門用語には初出のときに必ず説明を入れています。サンプルコードは原則 1行ずつコメント を付けています。分からない単語が出てきたら、まず巻末の「10_用語集」を引いてください。

1. このアプリは何をするもの？（30秒で理解）

工場などの現場で、従業員が 「いつ・どの作業に・何時間使ったか（＝工数）」 を記録・集計するためのWebアプリです。

  • 従業員が自分の作業時間を入力する
  • 休憩時間を差し引いて正味の工数を自動計算する
  • 班（チーム）単位・ショップ（職場）単位で集計・グラフ表示する
  • 管理者がデータのバックアップ・復元、操作履歴の確認を行う

詳しくは「00_導入と全体像」で説明します。

2. 技術構成（ざっくり）

4. 学習ロードマップ（目安）

完全初心者を想定した、無理のない進め方の目安です。焦らず、手を動かしながら 進めてください。

フェーズ1：まず動かす（1〜2週間）

  1. まず 000（引き継ぎ書）を読み、受け取る物をそろえる。パソコン操作に不安があれば、続けて 00a（超入門）を読む
  2. 00 を読んで全体像をつかむ（理解できなくてもOK、雰囲気をつかむ）
  3. 01 を読みながら、自分のPCに開発環境を作る
  4. 02 を読みながら、GitHubからコードを取得（クローン）できるようにする
  5. アプリをローカル（自分のPC）で起動して、画面を触ってみる

✅ ゴール：自分のPCで npm start と python manage.py runserver を実行し、ブラウザでアプリが表示できる。

フェーズ2：言語の基礎（2〜4週間）

  1. 03（HTML/CSS）→ 04（JS/TS）→ 06（Python）を読む
  2. 実際のコードを開いて「これはあの文法だな」と照らし合わせる

✅ ゴール：本アプリのコードを開いたとき、「何が書いてあるか雰囲気が読める」。

フェーズ3：フレームワークと本アプリの構造（3〜6週間）

  1. 05（React）と 07（Django）を読む
  2. 08（データベース・モデル）でデータ構造を理解する
  3. 小さな修正（文言の変更など）を試してみる

✅ ゴール：「この画面のこの文字を変えたい」を自力で実現できる。

フェーズ4：運用・保守(継続)

  1. 09 を読み、バックアップ・復元・デプロイを実際に練習する
  2. 15 の「🔴 すぐ」の物から、作業用のブランチで 1 つずつ直す

✅ ゴール：本番環境を壊さずに、運用作業とリリースができる。

6. PDF版・Web版と、コードのコピーのしかた

各 .md（マークダウン）ファイルは、次の 2 つの形でも読めます。

形 置き場所 向いている使い方
PDF版 kosu/pdf/ VS Code・Adobe Acrobat・ブラウザーで読む／紙に印刷する
Web版（HTML版） kosu/html/（入口は index.html）。インターネット上の https://oltotlo79-rgb.github.io/education/kosu/html/ にも同じ物があります ブラウザーで読む。コードの「コピー」ボタンで、字下げもそのままコピーできる

コードのコピーのしかた（見ている物ごとに違います）:

  • PDF を VS Code で見ている時: コードの枠の 1 行目の最初の文字の上から、最後の行の最後の文字の上までをマウスでなぞって選び、Ctrl ＋ C を押します。字下げ（行の先頭の空白）もそのままコピーできます（枠の上にオレンジの字で「なぞってコピーすると…」と書いてある枠だけは、次の「コピー」を使います）。
  • PDF を Adobe Acrobat（Acrobat Reader）で見ている時: 枠の右上の青い「コピー」を押します。Acrobat の中に窓が開き、コードが全部青く選ばれているので、そのまま Ctrl ＋ C を押して、窓は「閉じる」で閉じます（窓の下の赤い字「警告 : JavaScript ウィンドウ」は、PDF の中のボタンから開いた窓だという印で、エラーではありません）。Acrobat では、なぞってコピーしません（字下げと空の行が消えます）。
  • PDF を Chrome や Edge で見ている時: 枠の右上の青い「コピー」を押すと、Web 版のその場所が開きます。そこで「コピー」ボタンを押します。Chrome や Edge の PDF では、なぞってコピーしないでください（字下げが縮まり、空の行が消えます。Python は字下げが崩れると動きません）。
  • Web 版を見ている時: 枠の右上の「コピー」ボタンを押すだけです。

初めて出てきた言葉・書き方の説明（「初出の解説」）: コードの枠の下の、色の付いた箱は、その巻で初めて出てきた関数・書き方・記号などを、短く説明した物です。あとで探したい時は、巻末の「13_付録_出てくるコードとコマンドの一覧」（コードから意味を引く）と「14_付録_逆引き_やりたいことからコードを探す」（やりたいことから書き方を引く）を使います。

PDF・Web版を作り直す手順は「09_運用_保守_デプロイ.md」の §17.2 にあります。
