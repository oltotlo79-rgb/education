5.10 S-10 ヘルプの回数の上限が、頼みの見出しの書き方しだいで効かない

どこ: kosu/views/main_views.py 262 行目（Help）・379 行目（HelpPass）の throttle_classes = [ScopedRateThrottle]

今: 回数の上限の部品（DRF の ScopedRateThrottle）は、「同じ所からの頼みか」を、頼みに付いてくる見出し X-Forwarded-For（中継のサーバーが、本当の送り元の住所を書いて渡す見出し）で見分けます。DRF の初めの設定（NUM_PROXIES を書いていない時）では、見出しの中身を全部つなげた文字 で見分けます（手元に入っている DRF 3.14.0 の throttling.py 23〜40 行目で確かめた）。ところが、この見出しの中身は、いつも同じとは限りません。

  • 中継は、ふつう、本当の送り元の住所を見出しの いちばん後ろ に足して渡します。その前の部分は、送る側が自由に書けます。
  • 住所の後ろに、つなぐたびに変わるポート番号（:51234 など）が付く中継もあります。

どちらでも、見出しの中身が変わるたびに、別の所からの頼みとして数え直されます（本番の App Service の見出しの形は、この巻では確かめていません）。

✅ 手元で試した結果（手元の版）: 上限を 1 時間に 5 回にして、見出しの前の部分が毎回違う頼みを、同じ送り元から 6 回送ると、6 回とも 403 で、429 になりませんでした（下の③のテストが、手元の版では「[403, 403, 403, 403, 403, 403] != [403, 403, 403, 403, 403, 429]」で落ちる）。

何が困るか: ヘルプの API は、ログインしなくても呼べます。上限が効かないと、S-7 で防いだはずの、パスワードの総当たりができてしまいます。

直し方: 「同じ所か」を、見出しの いちばん後ろ（App Service の中継が足した、本当の送り元）の住所だけで見分ける部品 HelpRateThrottle を作り、Help・HelpPass で使います。住所にポート番号（:51234 など。つなぐたびに変わる）が付いていたら外します。

場所: kosu/views/main_views.py の 248 行目の前（Help の説明の前）

足すコード（この行の前に入れる）:

# ------------------------------------------------------------
# HelpRateThrottle: ヘルプの呼び出し回数の上限（Help・HelpPass で使う）
#   ScopedRateThrottle（DRF の部品）は、初めの設定では、頼みに付いてくる見出し X-Forwarded-For の
#   中身を全部つなげた文字で「同じ所か」を見分ける。見出しの前の部分は送る側が自由に書けるので、
#   書き方が変わるたびに「別の所」として数え直しになり、上限が効かない。
#   そこで、App Service の手前の中継が最後に足した、本当の送り元の住所（IP アドレス）だけで見分ける。
# ------------------------------------------------------------
class HelpRateThrottle(ScopedRateThrottle):
  # 「同じ所か」を見分ける文字（送り元の IP アドレス）を返す。
  #
  # 引数:
  #   request: HTTPリクエスト
  # 戻り値:
  #   str: 送り元の IP アドレス（ポート番号は付けない）
  def get_ident(self, request):
    xff = request.META.get('HTTP_X_FORWARDED_FOR')
    # 中継が無い時（手元で runserver を使う時など）は、つないできた相手の住所
    if not xff:
      return request.META.get('REMOTE_ADDR')
    # いちばん後ろが、App Service の中継が足した、本当の送り元
    addr = xff.split(',')[-1].strip()
    # "[2001:db8::1]:51234"（IPv6 とポート番号）の形なら、[ ] の中だけにする
    if addr.startswith('['):
      return addr[1:addr.find(']')] if ']' in addr else addr
    # "203.0.113.7:51234"（IPv4 とポート番号）の形なら、ポート番号を外す
    #   （ポート番号はつなぐたびに変わるので、付けたままだと毎回「別の所」になる）
    if addr.count(':') == 1:
      return addr.split(':')[0]
    return addr

▶ ここで初めて出てくるコード

  • .startswith()（Python）: 文字列が、その中身で始まっていれば True を返すメソッド。login_member.shop.startswith('組長以上') は、ショップが「組長以上(P,R,T,その他)」「組長以上(W,A)」のどちらかなら True です。
  • .find()（Python）: 文字列の中で、渡した文字が最初に出てくる位置（0 から数えた番号）を返すメソッド。見つからない時は -1 を返します。addr[1:addr.find(']')] は、[2001:db8::1]:51234 のような文字から、[ の次から ] の手前まで（2001:db8::1）を取り出します。
  • [-1]（Python）: items[-1] は、最後の 1 つです。[-2] は後ろから 2 つ目です。
  • ScopedRateThrottle（Django REST framework）: 同じ所（IP アドレス）からの呼び出しの回数を数えて、上限を超えたら 429（呼びすぎ）を返す部品。ビューに throttle_classes = [ScopedRateThrottle] と throttle_scope = 'help' を書くと、settings.py の REST_FRAMEWORK の DEFAULT_THROTTLE_RATES の 'help': '5/hour'（1 時間に 5 回）が上限になります。
  • .META（Django）: Django の request.META は、要求の見出しやサーバーの情報が入った辞書です。request.META.get("REMOTE_ADDR") で、送ってきた所のアドレスが分かります。
