付録: 出てくるコマンドと設定の一覧（機能ごと）

この資料について

00〜08 と「参考 HTTPS にする場合」のコードの枠に出てくる、PowerShell のコマンドとオプション・Windows のコマンド・SQL・psql・Python と Django・Rust と Topcoat の部品など 418 個を、27 の分類に分けて、1 つずつ説明した一覧です。

  • 本文との関係: どのコマンドや部品も、本文の中で初めて出てくるコードのすぐ下に、「▶ ここで初めて出てくるコード」の箱で同じ説明を載せています。この一覧は、それを機能ごとに並べ直した物です。
  • 使い方: 「この -StartupType は何だっけ？」「robocopy の /E は？」と思ったら、下の「分類の一覧」から分類を選んで探してください。HTML 版（onprem\html）なら、Ctrl ＋ F で、コマンドの名前で探すのがいちばん速いです。
  • オプションの書き方: PowerShell のオプションは、Get-Content -Tail のように、コマンドの名前と組にして載せています。同じ -Name でも、コマンドによって意味が少しずつ違うからです。-eq・-like・-join などは、どのコマンドでも同じ意味の演算子なので、それだけで載せています。
  • 「初めて出てくる所」の列: そのコマンドや部品が最初に出てくる資料と章です（04 7. アプリを Windows サービスにする は、04 の 7 章）。そこで、実際にどう使われているかを見られます。
  • 名前の決まり: 本番のサービスは webapp-prod、検証は webapp-stg、フォルダは D:\webapp\… です（04 の 4.1）。説明の中の名前も、これに合わせています。

ヒント: 1 つのコマンドを覚えたら、その分類の表の、近くにある物も読んでみてください。例えば PowerShell の表には、サービスを見る（Get-Service）・止める（Stop-Service）・始める（Start-Service）・始め直す（Restart-Service）が並んでいます。一緒に覚えると、困った時に打てるコマンドがぐっと増えます。
