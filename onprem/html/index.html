オンプレミス構築 教育資料

会社の仮想マシン（OS の Windows Server だけが入った状態）に、社内向けの Web アプリを自分で建てるための資料です。インフラの経験が無い人向けに、専門用語は出てくるたびに説明し、図とサンプルのコマンドを多く入れています。

読む順番

順 資料 内容 状態
1 00 基礎知識 コンピューターの中身から、サーバー・ネットワーク・Web・DB・メール・運用・セキュリティまでの基礎 できた
2 01 Windows Server の使い方 リモート デスクトップでのログイン、PowerShell、アカウントと許可、サービス、イベント ビューアー、タスク スケジューラ、ファイアウォール できた
3 02 SQL と PostgreSQL の使い方 データベースへのログイン、SQL の書き方（PostgreSQL 18 で動かした結果付き）、ユーザーと権限、設定、バックアップ、トラブル できた
4 03 技術スタックの比較と選定理由 OS・Web サーバー・データベース・アプリの作り方などの選択肢と、長所・短所、今回の選び方 できた
5 04 構築手順（Rust＋Topcoat版） PostgreSQL・アプリの Windows サービス化・IIS（HTTP）・ファイアウォール・メール・バックアップ・更新と切り戻し できた
6 05 構築手順（Django＋React版） 同じアプリを Django と React で作った場合。React の成果物は Django のプロジェクトの中に置き、Django（WhiteNoise）が同じサーバーで配信する。Python の部品の持ち込み、waitress、HTTP の設定（動かして確認済み） できた
7 06 トラブルシューティング 困ったときの動き方、切り分けの順番、まとめて確かめるスクリプト、ログの読み方、エラーの番号、症状別の原因と直し方、障害の記録の書き方 できた
8 07 付録 情報システム部門への依頼シート（文面と項目）、受け取り・構築・本番の前・毎日毎月・更新・年1〜2回のチェック表 できた
9 08 付録: よく使うコマンドの早見表 毎朝 3 分の確認・サービス・通信（HTTP の返事の番号）・ログ・ディスクとコピーと圧縮・PostgreSQL・更新と切り戻しの流れ・Windows の記録と予定の仕事を、やりたいこと別に（自分のパソコンで試せる練習と、実際に打った結果付き） できた
10 09 付録: 出てくるコマンドと設定の一覧 00〜08 と参考に出てくる 600 個あまりのコマンド・オプション・PowerShell の書き方・SQL・XML の設定・コードの部品を、機能ごとの表で引ける（PowerShell のオプションは、コマンドと組にして説明）。本文でも、初めて出てくるコードのすぐ下に、同じ説明の箱（▶ ここで初めて出てくるコード）がある できた
11 10 付録: 逆引き 「サービスを止めたい」「ポートにつながるか確かめたい」のような、やりたいことからコマンドと設定を引ける 200 個あまりの表。本文に出てくる所と、合わせて覚えておくとよいコマンドも載せている できた
参考 参考 HTTPS にする場合 HTTPS と証明書の考え方、社内で証明書を用意する方法、あとから HTTPS に切りかえる手順（Rust 版・Django 版） できた

この資料の前提

  • データベースは、仮想マシンの中に PostgreSQL を入れて作る。
  • 社内では HTTPS を使えないため、HTTP（80 番）で動かす。
  • 版は 2026-11-01 時点（Windows Server 2025／2022、PostgreSQL 18.6、IIS 10＋URL Rewrite 2.1＋ARR 3.0、WinSW 2.12.0、Rust 1.99.1、Topcoat 0.11.0）。
  • 図（images/）は、すべて同じ色と描き方にそろえています。図はたとえで描いているので、細かい所は本文と表で確かめてください。

PDF

pdf/ に、各資料の PDF があります（図とサンプルを含む。印刷や、ネットにつながらない所で読むときに使う）。資料を直したら、リポジトリの一番上で python _build_pdfs.py onprem/（資料の名前）.md を動かして作り直します。
