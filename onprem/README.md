# オンプレミス構築 教育資料

会社の仮想マシン（OS の Windows Server だけが入った状態）に、社内向けの Web アプリを自分で建てるための資料です。インフラの経験が無い人向けに、専門用語は出てくるたびに説明しています。

| 2 | [01 構築手順（Rust＋Topcoat版）](01_構築手順_Rust_Topcoat版.md) | PostgreSQL・アプリの Windows サービス化・IIS（HTTP）・ファイアウォール・メール・バックアップ・更新と切り戻し | できた |
| 3 | 02 構築手順（Django＋React版） | 同じアプリを Django と React で作った場合。React の成果物は Django のプロジェクトの中に置き、Django が同じサーバーで配信する | 作成中 |
| 4 | 03 付録 | 情報システム部門への依頼シート、チェック表 | 作成中 |
| 参考 | 参考 HTTPS にする場合 | HTTPS と証明書の考え方、あとから HTTPS にする手順 | 作成中 |

## この資料の前提

- データベースは、仮想マシンの中に PostgreSQL を入れて作る。
- 社内では HTTPS を使えないため、HTTP（80 番）で動かす。
- 版は 2026-11-01 時点（Windows Server 2025／2022、PostgreSQL 18.6、IIS 10＋URL Rewrite 2.1＋ARR 3.0、WinSW 2.12.0、Rust 1.99.1、Topcoat 0.11.0）。
